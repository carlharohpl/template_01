# RMS MIP1 Flappy Bird

Phaser/Vite playable ad scaffold for a simple tap-to-flap RMS game.

## Current Scope

- Uses `projects/sizzle-sort-multi-goal` network-ready base.
- Uses only campaign assets copied from `incoming/rms-mip1-flappybird/assets`.
- Renders a fullscreen radial background from `#ffffff` to `#ff9a9f`.
- Implements the first gameplay scene only: tap to fly, avoid pipes, collect RMS product items, and update score.
- Later promo/end scenes can be layered on top of the existing completion hook.

## Build

```sh
npm run build
```
