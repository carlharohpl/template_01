# Cape Diablo Catch MIP2

Portrait-first playable ad adapted from `templates/drag-match-template`.

## Flow

- `Scene1`: Cape Diablo products fall slowly while the user drags the gift box left and right to catch 3 products.
- `Scene2`: Reward scene with rotating light rays and CTA. EndScene is intentionally not implemented yet.

## Assets

All runtime media in `src/assets/` comes from `incoming/cape-diablo-catch-mip2/assets/`.
